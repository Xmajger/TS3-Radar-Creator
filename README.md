# TS3 Radar Creator

A lean and efficient tool for creating radar configurations for TS3. Designed to streamline workflows and provide precise results.

## 🚀 Features
*   **Easy Creation:** Generate radar data quickly and intuitively.
*   **Performance:** Built on Electron – stable and reliable.
*   **Configurable:** Full control over your parameters.
*   **Platform Support:** Optimized for Windows.
